# 器件管理模块说明文档

## 📋 模块概述

器件管理模块是用于管理硬件接线仿真系统中所有器件的后台管理页面，支持器件的增删改查操作。

## 🎯 功能特性

### 1. 器件列表展示
- ✅ 表格形式展示所有器件信息
- ✅ 支持分页显示
- ✅ 展示器件ID、名称、类型、电压、协议、引脚数量等信息
- ✅ 支持多选批量操作

### 2. 搜索与筛选
- ✅ 按器件名称搜索
- ✅ 按器件类型筛选（电源、传感器、控制器、执行器）
- ✅ 按通信协议筛选
- ✅ 一键重置筛选条件

### 3. 器件新增
- ✅ 填写器件基本信息（ID、名称、类型、电压、协议）
- ✅ 选择器件图标和颜色
- ✅ 配置引脚信息（ID、标签、类型、电压、协议）
- ✅ 动态添加/删除引脚
- ✅ 表单验证

### 4. 器件编辑
- ✅ 修改器件所有信息
- ✅ 器件ID不可修改（防止引用错误）
- ✅ 实时表单验证

### 5. 器件详情
- ✅ 查看器件完整信息
- ✅ 美观的卡片式布局
- ✅ 引脚信息网格展示

### 6. 器件删除
- ✅ 单个删除（二次确认）
- ✅ 批量删除
- ✅ 删除前提示

## 🚀 使用说明

### 1. 访问页面
在系统侧边栏点击「器件管理」菜单即可进入

### 2. 搜索器件
- 在搜索框输入器件名称
- 选择器件类型或通信协议进行筛选
- 点击「搜索」按钮

### 3. 新增器件
1. 点击右上角「新增器件」按钮
2. 填写器件基本信息
3. 点击「添加引脚」配置引脚信息
4. 点击「确定」保存

### 4. 编辑器件
1. 在器件列表中找到目标器件
2. 点击操作列的「编辑」按钮
3. 修改信息后点击「确定」保存

### 5. 查看详情
- 点击操作列的「详情」按钮
- 查看器件完整信息和引脚配置

### 6. 删除器件
- 单个删除：点击「删除」按钮
- 批量删除：勾选多个器件后点击「批量删除」

## 🔧 技术实现

### 数据结构
```javascript
{
  id: 'arduino',              // 器件唯一标识
  name: 'Arduino UNO',        // 器件名称
  category: '控制器',          // 器件类型
  icon: 'el-icon-cpu',        // 图标类名
  voltage: '5V',              // 工作电压
  protocol: 'Multiple',       // 通信协议
  color: '#95E1D3',          // 显示颜色
  description: '描述信息',    // 器件描述
  pins: [                     // 引脚配置数组
    {
      id: '5v',              // 引脚ID
      label: '5V',           // 引脚标签
      type: 'output',        // 类型（input/output）
      voltage: 5,            // 电压值
      protocol: 'Power'      // 协议（可选）
    }
  ]
}
```

### API 接口说明

#### 1. 获取器件列表（分页）
```javascript
GET /api/component/list
参数: { pageNum, pageSize, name, category, protocol }
```

#### 2. 新增器件
```javascript
POST /api/component/add
数据: { id, name, category, icon, voltage, protocol, color, description, pins }
```

#### 3. 修改器件
```javascript
PUT /api/component/update
数据: { id, name, category, icon, voltage, protocol, color, description, pins }
```

#### 4. 删除器件
```javascript
DELETE /api/component/delete/:id
```

#### 5. 批量删除
```javascript
DELETE /api/component/batch-delete
数据: { ids: ['id1', 'id2'] }
```

更多接口请查看 `src/api/component.js`

## 🔄 与硬件仿真模块的集成

### 数据同步
器件管理模块中创建的器件可以直接在硬件接线仿真模块中使用。建议：

1. 后端统一管理器件数据
2. 仿真模块从后端获取器件库数据
3. 两个模块使用相同的数据格式

### 集成步骤
1. 在 `HardwareSimulationX6.vue` 中引入器件API：
```javascript
import { getAllComponents } from '@/api/component'
```

2. 在组件挂载时获取器件数据：
```javascript
mounted() {
  this.loadComponentsFromAPI()
}

methods: {
  async loadComponentsFromAPI() {
    try {
      const res = await getAllComponents()
      // 按类型分组
      this.componentCategories = this.groupByCategory(res.data)
    } catch (error) {
      console.error('获取器件失败:', error)
    }
  }
}
```
